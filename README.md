## 🚀 Key Website Features

1. **Instant Bilingual Switcher (Hindi & English):**
   - 300+ keys translation dictionary.
   - Switches language across every navigation item, heading, paragraph, card, placeholder, and legal policy without page reload.
   - Persists user language preference via `localStorage` (default: Hindi).
   - Dynamic font switching: **Poppins** (English) & **Noto Sans Devanagari** (Hindi).

2. **100% Responsive & Mobile-First:**
   - Smoothly adapts from 320px mobile screens, phablets, tablets, laptops, desktops, to 4K displays.
   - Mobile slide-out drawer navigation with hamburger toggle and backdrop blur.
   - Sticky bottom quick action bar for mobile devices (Call Now, WhatsApp Chat, Quick Inquiry).
   - Floating WhatsApp button with pre-filled project inquiry message.

3. **Core Business Verticals (MOA Clause 3(a) & 3(b) Aligned):**
   - **Civil Construction & Building Infrastructure**
   - **Public & Heavy Infrastructure (Roads, Bridges, Canals)**
   - **Solar Energy Projects (Rooftop & Ground-Mounted)**
   - **Solar Equipment Supply & Trading**
   - **Water Supply, Pipelines & Irrigation Networks**
   - **Real Estate & Land Colonization**
   - **Construction Material & Heavy Machinery Logistics**
   - **Skill Development & Vocational Training**
   - **Human Resource & Manpower Solutions**
   - **Building & Infrastructure Maintenance (AMC Services)**
   - **Food Processing & Agro-Ration Supply Chain**

4. **Interactive Features & Modals:**
   - Detailed modal popups for every business vertical with full technical scope.
   - Filterable Project & Gallery grid with lightbox viewer.
   - Animated Milestone Counters with IntersectionObserver scroll reveal.
   - Interactive validated contact form with one-click WhatsApp / Email transmission.
   - Copy-to-clipboard for statutory numbers (CIN, GSTIN, PAN).
   - Embedded Google Map for Arar More, Gopalganj, Bihar.

5. **Legal & Compliance Infrastructure:**
   - Dedicated interactive modals for **Terms & Conditions**, **Privacy Policy**, and **Statutory Disclaimer**.
   - AOA Article 79 execution requirements compliance.
   - FSSAI, APMC, RERA, and MCA statutory clarity.

## 🌐 Deployment Instructions

### GitHub Pages (Recommended)
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Branch**, select `main` (or `master`) branch and folder `/ (root)`.
3. Click **Save**. The website will be live in seconds at `https://<username>.github.io/<repo-name>/`.

### Vercel / Netlify
1. Import the Git repository directly.
2. No build command needed (Static HTML).
3. Set publish directory to `./`.
4. Deploy instantly.
